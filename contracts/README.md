# Boundary proposals

Files under proposed/ are draft local S7 boundaries only. They do not validate
runtime inputs yet or establish owner acceptance. Shared docio, Pointer,
providers/callledger and evalkit wire types remain owned by their source modules.

Collection/item IDs are opaque; raw-content identity, processing revision and
collection generation are distinct. Proposed page dimensions will use S2's agreed
source grid. Word/line boxes, transforms and Pointer wire fields will consume the
joint owner contract rather than a competing local canonical definition.

The schema file's parseability is structural, not ingestion/security acceptance.
Decoded pixel count, MIME signatures, total bytes and transactional collection caps
require implementation and adversarial tests in later slices.
